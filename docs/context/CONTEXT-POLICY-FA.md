# سیاست استفاده از Context Mode — فقط MCP، اختیاری

**تاریخ بررسی:** ۲۱ اکتبر ۲۰۲۶  
**دامنه:** پروژه‌های دارای خروجی‌های حجیم و مجاز؛ نصب و بهره‌برداری الزامی نیست.

## ۱. تصمیم پیکربندی

- فقط MCP مستقل؛ بدون Antigravity Plugin کامل، `context-mode.mdc` همیشه‌فعال یا Hookهای `preToolUse`، `postToolUse`، `sessionStart` و `stop`.
- اگر اتصال برقرار نشد، پروژه با ابزارهای پیش‌فرض Antigravity ادامه پیدا کند.
- اجرای دستور، ذخیره خروجی، نصب بسته و فعال‌سازی خودکار به مجوزهای معمول ورکفلو وابسته‌اند.
- `ctx_execute` محیط ایمنی برای کد نامطمئن یا بی‌مجوز نیست؛ به دسترسی‌های فرایند اعتماد می‌کند.

## ۲. طبقه‌بندی پیش از استفاده

| طبقه داده | مثال | سیاست |
|---|---|---|
| عمومی | راهنمای رسمی، مستندات متن‌باز | مجاز در چارچوب Scope |
| داخلی کم‌حساسیت | لاگ تست ساختگی، خروجی Build عاری از شناسه | مجاز پس از بررسی و Redaction |
| محرمانه | توکن، Secret، PII، داده مشتری، لاگ Production | ممنوع بدون مجوز خاص و سیاست حفاظت داده؛ پیش‌فرض عدم استفاده |
| کد اجرایی ناشناخته | اسکریپت خارجی، فایل دانلودشده | اجرای مستقیم در Context Mode ممنوع |

## ۳. قابلیت‌ها و کنترل‌ها

- `ctx_execute`, `ctx_execute_file`: فقط کد/فرمان تأییدشده روی داده مجاز؛ خروجی را قبل از ارسال بازبینی کنید.
- `ctx_batch_execute`: صرفه‌جویی بالقوه در خروجی زیاد، اما خطر مخفی‌شدن جزئیات؛ فهرست فرمان‌ها را قبل از اجرا کنترل کنید.
- `ctx_index`, `ctx_fetch_and_index`: فقط بعد از طبقه‌بندی، بررسی مجوز ذخیره‌سازی و Retention.
- `ctx_search`: برای یافتن بخش مرتبط، نه جایگزین بررسی کامل Artifact.
- `ctx_stats`: شاخص درون‌ابزاری است؛ لزوماً برابر با مصرف توکن/هزینه Antigravity نیست.
- `ctx_doctor`: ممکن است برای Plugin کامل تعداد Hookها را چک کند؛ نبود Hook در روش MCP-only عمدی است.
- `ctx_purge`: حذف غیرقابل‌بازگشت داده‌های ذخیره‌شده؛ با مجوز صریح.

## ۴. شرایطی که باید Context Mode را کنار گذاشت

- نیاز به استدلال مبتنی بر تمام خطوط Diff یا شواهد اصلی در Security Review.
- تردید درباره وجود Secret یا اطلاعات شناسایی‌کننده در داده‌ها.
- عدم امکان بازیابی Log کامل، Exit Code یا Artifact اصلی.
- تداخل در رفتار Agent، کندی محسوس یا افزایش Rework.
- نبود پشتیبانی مناسب روی نسخه فعلی Node یا Antigravity.
