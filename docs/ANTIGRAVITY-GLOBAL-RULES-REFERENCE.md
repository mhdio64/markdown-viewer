# Global Engineering Defaults

1. Follow repository-specific architecture and approved ticket boundaries.
2. Never claim completion without executing appropriate verification commands.
3. Require human approval before commits, pushes, merges, deployments, destructive commands, or production changes.
4. Never expose credentials; use least-privilege MCP servers and approvals.
5. Prefer understandable code and tests; avoid redundant abstractions.
6. Reply to the user in Persian. Write source code and code comments in English.
